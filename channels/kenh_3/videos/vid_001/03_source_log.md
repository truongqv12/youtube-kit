# 03 Source Log: Dizziness and Balance (Morning Dizziness)

## Official & Primary Sources

### 1. 厚生労働省 (MHLW) / 日本老年医学会
- **Type:** `official` / `primary`
- **Topic:** 起立性低血圧（Orthostatic Hypotension）と高齢者のふらつき
- **Key Findings:** 加齢により自律神経の働きや圧受容反射が低下し、起き上がった際に脳への血流が一時的に減少しやすい。睡眠中（横になっている状態）からの急な立ち上がりは血圧低下を招く。脱水もリスクを悪化させる。

### 2. 一般社団法人 日本耳鼻咽喉科頭頸部外科学会
- **Type:** `primary`
- **Topic:** めまい・ふらつきの受診の目安と原因
- **Key Findings:** 高齢者のふらつきの多くは内耳（三半規管など）の加齢性変化や良性発作性頭位めまい症（BPPV）が関与する。手足のしびれやろれつが回らない等の症状があれば脳外科等へ、耳鳴りや繰り返すふらつきがあれば耳鼻咽喉科への受診を推奨。

### 3. 一般社団法人 日本めまい平衡医学会
- **Type:** `primary`
- **Topic:** 高齢者の平衡機能低下のメカニズム
- **Key Findings:** ふらつきは単一の原因ではなく「多因子性」。内耳の感度低下、視力低下、下肢の深部感覚の衰えなどが重なることで姿勢制御が難しくなる。血圧変動や内服薬の副作用も一因となる。

### 4. 介護予防事業（自治体・リハビリテーション専門機関）
- **Type:** `official` / `primary`
- **Topic:** 安全な起き上がり方と転倒予防
- **Key Findings:** 急な動作は避ける。「仰向けからひざを立てる」「横向きになる」「足をおろす」「手をついてゆっくり起きる」という段階的動作が有効。立った直後にふらつく場合は「立ってから3秒静止」して血圧とバランスを安定させることが推奨される。

### 5. 日本救急医学会 / 厚生労働省（熱中症・脱水予防啓発）
- **Type:** `official`
- **Topic:** 高齢者の脱水傾向と水分補給
- **Key Findings:** 高齢者はのどの渇きを感じにくく、就寝中に汗や呼吸で水分が失われるため、起床時は軽度の脱水状態（血液がドロドロになりやすい状態）になりやすい。起床時のコップ一杯の水がふらつき予防や血流改善に意義がある。

### 6. 国立長寿医療研究センター (NCGG)
- **Type:** `primary`
- **Topic:** 高齢者の睡眠の質と日中の機能・転倒リスク
- **Key Findings:** 睡眠リズムの乱れや質の低下は、自律神経の調整機能に影響を与え、日中の疲労感や起床時のふらつき、転倒リスクの増加に関与する。夜の過ごし方（光の調整など）の見直しが間接的に朝の安定に寄与する。
