# Spoken Narration Rhythm

## Purpose
Guide spoken Japanese that sounds natural for older listeners in calm explanatory content.

## Core rules
- Write for the ear.
- Prefer one clear point per line.
- Mix short and medium lines. Use longer lines only when the meaning truly needs it.
- Let important lines land with plain wording.
- A useful script sounds like a considerate guide speaking calmly, not like a handbook being read aloud.

## Preferred rhythm patterns
- short setup → medium explanation → short landing
- concrete daily-life observation → practical suggestion → soft caution
- familiar scene → why it matters → low-pressure next step

## Avoid
- 3 or more lines in a row with the same grammar shape
- overuse of `そして`, `また`, `さらに`, `そのため`
- stacked abstract nouns
- sentence-final softeners repeated in the same pattern too often
- over-polite stiffness that creates emotional distance

## Example
Less natural:
- `朝の水分補給は重要です。`
- `朝の水分補給は血流維持に役立ちます。`
- `朝の水分補給は転倒予防にもつながります。`

More natural:
- `朝は、思ったより水分が足りていないことがあります。`
- `まず一口でも飲んでおくと、動き始めが少し楽な方もいます。`
- `ふらつきやすい方は、急がないことも大切です。`
