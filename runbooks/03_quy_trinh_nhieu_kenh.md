# Multi-Channel Workflow

## Correct model
One shared engine, multiple isolated channel states.

## Shared across all channels
- `core/`
- `knowledge/`
- `compiled_prompts/`
- `runbooks/`

## Isolated per channel
- `profile/00_channel_seed.json`
- All profile files generated by Step 00
- `00_host_character_sheet.json`
- `assets/host_reference/`
- `assets/branding/`

## When to create a separate channel
Only create a separate channel if you need genuine brand-level differences:
- Different host
- Different visual style
- Different title / thumbnail bias
- Different storytelling approach
- Different primary content pillar

## Host consistency rule
Do not reuse the same channel if the host identity changes.
For each channel, keep one approved character sheet and one approved reference image set.
