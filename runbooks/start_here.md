## Manual run rule
When running by hand with AI:
1. paste the compiled prompt
2. paste every file listed under `Required reads`
3. require the model to return **Preflight** first
4. continue only if preflight proves the files were read and rules were extracted

## Folder strategy
- Shared logic lives in `core/`, `knowledge/`, `compiled_prompts/`
- Channel identity starts from `channels/<channel_key>/profile/00_channel_seed.json`
- Derived channel profiles are generated by Step 00
- One video job lives in `channels/<channel_key>/videos/<video_id>/`
