## 📖 Overview

This pipeline automates the entire YouTube video production workflow for senior health channels (audience 60+), using AI agents (Claude, Gemini, etc.) to execute each step.

### Key Features

- 🌱 **Seed-driven**: Fill in a single `00_channel_seed.json` (6 fields) → all channel profiles are generated automatically
- 🔬 **Research-first**: Mandatory research from official sources before script writing — no fabrication, no competitor copying
- 🎙️ **TTS-safe scripts**: Scripts written as canonical units — each line is a natural spoken sentence, ready to paste into TTS
- 🧑‍🦳 **Character-locked host**: Recurring host identity is locked as channel state before image/video prompt generation
- 🖼️ **Line-context locked prompts**: Image prompts (Nano Banana) are semantically locked to each script line
- 🎥 **Motion-only video prompts**: Video prompts (Veo 3) describe motion only, without repeating image content
- 📦 **Publication package**: Generates title, thumbnail concepts, description, keywords, and 2 Shorts derivatives
- 📡 **Multi-channel**: One shared engine, isolated per-channel state

## 🚀 Quick Start

### Prerequisites

- **AI Agent**: Claude Code, Gemini CLI, or any AI agent capable of reading files and returning artifacts
- **Web access**: Required for Step 03 (research) and Step 10 (publication package)
- **No code installation needed**: This pipeline is prompt-driven — the AI agent reads prompts and generates artifacts

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/seniorhealth_pipeline_topic_first_v3.git
cd seniorhealth_pipeline_topic_first_v3
```

### 2. Create a new channel

```bash
# Create channel directory
mkdir -p channels/my_channel
```

Copy and fill in the seed file:

```bash
cp bootstrap/00_channel_seed.template.json channels/my_channel/00_channel_seed.json
```

The seed has only **6 fields**:

```json
{
  "channel_name": "Your Channel Name",
  "channel_description": "Short description of what the channel helps viewers understand or do.",
  "audience_age": "60+",
  "language_country": "ja-JP / Japan",
  "video_style": "manga editorial clean / seinen soft educational",
  "channel_niche": "senior health daily wellness"
}
```

### 3. Run Step 00 — Generate all profiles

Paste the compiled prompt `00_run_build_all_profiles_from_seed.md` into your AI agent with `TARGET_CHANNEL=my_channel`.

The AI will generate:
- `00_channel_config.json`
- `00_editorial_profile.json`
- `00_publication_profile.json`
- `00_visual_profile.json`
- `00_language_profile.json`
- `00_profile_inference_report.md`

### 4. Create a new video

```bash
mkdir -p channels/my_channel/videos/vid_001
```

Copy and fill in the intake:

```bash
cp bootstrap/01_video_intake.template.json channels/my_channel/videos/vid_001/01_video_intake.json
```

### 5. Run the pipeline in order

```
Step 00  →  Build profiles from seed
Step 01  →  Video intake
Step 02  →  Topic strategy (lock micro-topic)
Step 03  →  Mandatory research (web access required)
Step 04  →  Policy gate (health safety check)
Step 05  →  Outline builder
Step 06  →  Canonical script writer (TTS-safe)
Step 06C →  Host character lock
Step 07  →  Image prompt builder (Nano Banana, line-locked)
Step 08  →  Video prompt builder (Veo 3, motion-only)
Step 09  →  Three-column exporter + QC
Step 10  →  Publication package (web access required)
```

## 🛡️ Quality Guardrails

### Health Content
- No fabricated health information
- No diagnostic language
- No cure promises or doctor-replacement framing
- Prefer "daily routine" framing over disease-name shock
- Include consult-a-clinician advice when appropriate

### Script
- Each line is one canonical unit — TTS-safe, sounds natural when read aloud
- Passes 4 gates: TTS-safe → Naturalness → Rhythm → Breath-group
- No headings, bullets, emojis, speaker tags, or stage directions
- Duration must fall within `target_min` — `target_max` range
- Each line must also be visual-beat-safe: easy to support with one keyframe or motion beat for YouTube

### Recurring Character
- If the channel uses a host, create or verify `00_host_character_sheet.json` before Step 07
- Host identity is channel state, not a per-video rewrite
- Prefer 1-3 approved reference images in `assets/host_reference/`
- Host prompts must be identity-lock first: reference → identity packet → scene delta → action delta → drift blockers
- Do not change hair, age, outfit family, body type, style, or youthfulness

### Image Prompts
- Semantically locked to each script line — no generic illustrations
- Must resolve `line_context_frame` before writing the prompt
- Characters aged 60+ must explicitly describe aging features (gray hair, wrinkles, posture)
- Locale-correct (architecture, signage, clothing match the target country)
- Host prompts must use `prompt_identity_packet` from the character sheet when available

### Video Prompts
- Motion-only — no re-description of the source image
- Silent audio: `(Silent video, no audio).`
- No lip sync, no direct-to-camera speech
- No ambience, foley, room tone, music, soundscape, or any audio cue
- For host rows, preserve identity from source image/reference; do not recreate face, hair, or wardrobe in the video prompt

## 📡 Multi-Channel Support

The pipeline supports running multiple YouTube channels on a single shared engine:

| Shared | Per-Channel |
|--------|-------------|
| `core/` | `00_channel_seed.json` |
| `knowledge/` | All profiles generated by Step 00 |
| `compiled_prompts/` | `00_host_character_sheet.json` |
| `runbooks/` | `assets/host_reference/` |
| `steps/` | `assets/branding/` |
|  | All `videos/` directories |

**When to create a separate channel?** When you need genuine brand-level differences: different host, different visual style, different storytelling approach, or different content pillars.

## ⚙️ Running with an AI Agent

### Golden Rules for Manual Execution

1. **Paste the compiled prompt** for the corresponding step into the AI agent
2. **Paste all files** listed under `Required reads` — the AI must read them before executing
3. **Require Preflight** — the AI must return `=== PREFLIGHT START ===` proving it read all files and extracted the rules
4. Only proceed when Preflight is correct
5. The AI returns artifacts inside `=== ARTIFACT: filename.ext ===` envelopes

### Example Prompt

```
TARGET_CHANNEL=kenh_2
TARGET_VIDEO=vid_001

[Paste content of compiled_prompts/06_run_script_writer_canonical.md]
[Paste core/system_principles.md]
[Paste core/canonical_script_unit_standard.md]
[Paste channels/kenh_2/00_channel_config.json]
[Paste channels/kenh_2/00_language_profile.json]
[Paste channels/kenh_2/videos/vid_001/05_outline.json]
...
```

## ❓ FAQ

<details>
<summary><b>Does this pipeline require writing code?</b></summary>

No. This is a prompt-driven system — you fill in input JSONs, paste prompts into an AI agent, and the AI generates artifacts. No Python, Node.js, or any runtime installation needed.
</details>

<details>
<summary><b>Which AI agent should I use?</b></summary>

Any AI agent capable of: reading multiple files at once, accessing the web (for Steps 03 & 10), and returning structured JSON/CSV artifacts. Recommended: Claude Code, Gemini CLI, or equivalent.
</details>

<details>
<summary><b>Does it support languages other than Japanese?</b></summary>

The pipeline is designed to be flexible via the `language_country` field in the seed. However, the current knowledge base (`knowledge/japanese/`) is focused on Japanese. To use another language, you need to add a corresponding knowledge base.
</details>

<details>
<summary><b>Can it be used for niches other than senior health?</b></summary>

Yes, but you will need to adjust `policy_guardrails.md`, the knowledge base, and the demographic lock in `prompt_description_grammar.md` to fit the new niche.
</details>
