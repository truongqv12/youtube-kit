# System Principles

1. Prompt does not replace state.
2. Artifacts are the source of truth.
3. `00_channel_seed.json` is the only manually authored channel seed. All legacy channel profiles are derived state generated by Step 00.
4. The pipeline must remain backward-compatible by emitting:
   - `00_channel_config.json`
   - `00_editorial_profile.json`
   - `00_publication_profile.json`
   - `00_visual_profile.json`
   - `00_language_profile.json`
5. Health or advice videos still require mandatory research before script writing when the topic needs it.
6. Final export must contain exactly 3 columns:
   - `script_text`
   - `prompt_img_nano`
   - `prompt_video_veo3`
7. `script_text` must come directly from `canonical_script_units` in order, with no later rewriting.
8. Every canonical script unit must be a TTS-safe natural spoken narration line.
9. Language profile and visual profile must be respected by script and prompt builders.
10. If required inputs are missing, the step must fail.
11. This pipeline is for podcast / narration / explainer style videos, not film scenes.
12. The image prompt defines the semantically locked keyframe. The Veo prompt defines motion only for image-to-video.
13. Visible text that appears inside the generated image or video must follow `channel_language` and locale governance.
14. If `non_dialogue_mode=true` or `voiceover_mode=narration_only`, on-screen spoken dialogue must remain disabled unless the config explicitly opts in.
15. Prompt builders must resolve line context before writing final prompts. Never jump directly from a raw script line to a generic topic illustration.
16. If `veo_audio_mode=silent` or `audio_prompt_mode=silent_motion_only`, Veo prompts must include `(Silent video, no audio).` and must NOT request ambience, foley, room tone, or any generated soundscape. Audio is handled entirely by external TTS. This policy reduces `PUBLIC_ERROR_AUDIO_FILTERED` from Veo 3.1 safety system.
17. Host or recurring character identity must be treated as channel state, not re-invented per row. When a host is used, `00_host_character_sheet.json` is the identity source of truth.
18. Scripts for YouTube narration must be both TTS-safe and visual-beat-safe: each canonical unit should be easy to speak aloud and easy to support with one clear keyframe or motion beat.
