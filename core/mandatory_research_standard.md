# Mandatory Research Standard

- Health content requires external research.
- Topic strategy is not evidence.
- Minimum 5 sources, including at least 3 official or primary sources.
- For a Japan-facing senior-health channel, prefer at least 2 Japan-based official / primary sources when the topic allows.
- Competitor videos are not fact sources.
- If there is no real web access, mandatory research must fail.
- Research output must separate:
  - facts
  - practical guidance allowed by evidence
  - unknowns / uncertainty
  - when to ask a clinician
- Build evidence only for claims the script is likely to use.
- No script writing before research is complete.
- Each source in the log must be labeled as one of:
  - `official`
  - `primary`
  - `supporting`
- If only supporting sources exist and no official or primary support can be found, the step fails.
