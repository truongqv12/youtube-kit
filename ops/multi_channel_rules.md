# Multi-Channel Operating Rules

## 1. Do not duplicate the entire repo
Use a single shared engine.

## 2. Each channel must have its own state
At minimum, separate:
- `00_channel_seed.json`
- All profiles generated by Step 00
- Host references
- Branding assets

## 3. Lock the fixed host from the start
If a channel uses a 65-year-old female host, do not let subsequent videos drift to a younger person or a different face.

## 4. Publication must also be per-channel
Do not use the same title and thumbnail formula for all channels.

## 5. Market learning should be saved per channel
Thumbnail references, title patterns, keyword clusters, and readability notes should be stored in `assets/thumb_research/` for each channel.
